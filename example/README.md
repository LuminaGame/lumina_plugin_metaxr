# metaxr_example

Bring-up app for lumina_plugin_metaxr passthrough on a Quest: the openxr session and frame loop, a passthrough
underlay under turning cubes. A toggles passthrough, B toggles the edge style. Logs under `[metaxr_example]`,
LuminaOpenXR and LuminaMetaXR.

```bash
flutter build apk --release --target-platform android-arm64
```
